# 云韵音乐 · iOS 未签名包(GitHub 自动编译 + Windows 自签安装)
#
# 没有 Mac 也能出 iOS 安装包,思路是:
#   本地推代码 → GitHub 的 macOS 机器自动编译 → 下载未签名 ipa
#   → 在 Windows 上用 Sideloadly 拿你自己的 Apple ID 自签 → 装进 iPhone
#
# 硬规则(绕不开):iPhone 装 App 必须有苹果签名,签名只能在 macOS 上产出,
# 所以"编译"这步必须借别人的 Mac —— GitHub Actions 每个月免费给够用。
#
# 仓库只放 App 源码:go_backend / backend / tp 已在 .gitignore 里排除,
# 安装包(*.apk / *.zip / 云韵音乐-*/)和编译产物也不会进仓库。

# ========== 1) 建仓库并上传(图形界面,不用敲命令)==========
#  a. 装 GitHub Desktop:https://desktop.github.com  (自带 git,免配置)
#  b. 登录 GitHub 账号(没有先注册,免费)
#  c. 菜单 File → Add local repository → 选 c:\Users\Administrator\Desktop\yin
#     提示「不是 Git 仓库,是否在此创建?」→ 点 create a repository
#  d. 左下 Summary 填「首次提交」→ 点 Commit to main
#  e. 右上 Publish repository:
#        Name: yin                     ← 仓库名
#        ☑ Keep this code private      ← 必须勾!(里面有接口地址 / AES 相关代码)
#     点 Publish repository
#
# 提交前先看「Changes」列表:里面不应该出现 go_backend / backend / tp / *.apk。
# 出现了就说明 .gitignore 没生效,先别提交。
#
# —— 想用命令行的话(git 已安装时)——
#   cd c:\Users\Administrator\Desktop\yin
#   git init -b main
#   git add .
#   git status --short          # 核对:不应出现 go_backend/ backend/ tp/ 与 *.apk
#   git commit -m "首次提交"
#   git remote add origin https://github.com/<你的用户名>/yin.git
#   git push -u origin main

# ========== 2) 让 GitHub 自动编译 ==========
# 推上去后打开:https://github.com/<你的用户名>/yin/actions
#   左侧选「iOS 未签名 ipa」→ 右侧 Run workflow
#   (之后只要 flutter_app 有改动推到 main,会自动跑)
# 约 5~10 分钟。绿色对勾=成功;红了就点开那一步看日志。
#
# 免费额度:私有仓库 2000 分钟/月,macOS 按 10 倍折算 → 约 20 次 iOS 构建/月。

# ========== 3) 下载 ipa ==========
# 点开那次运行 → 页面底部 Artifacts → 下载 ios-unsigned-ipa(zip)
# 解压得到 YunYunMusic-unsigned.ipa

# ========== 4) 装进 iPhone(Windows 上就能做)==========
#  a. 装 Sideloadly:https://sideloadly.io
#  b. iPhone 数据线连电脑,手机上点「信任此电脑」
#  c. Sideloadly:IPA 选刚下载的 ipa;Apple ID 填你自己的(免费账号就行);Start
#  d. 手机上:设置 → 通用 → VPN 与设备管理 → 信任你的开发者证书
#  e. 打开 App
#
# 注意:免费 Apple ID 的签名 7 天过期,过期后重跑一次第 4 步即可;
# 想自动续签可装 AltStore(Windows 版 AltServer 常驻,同一 WiFi 下自动续签)。

# ========== 5) 换接口地址(devtunnel 换域名时)==========
# 仓库 Settings → Secrets and variables → Actions → Variables
#   新建 API_BASE_URL = https://xxxx.devtunnels.ms
# 之后重新跑一次工作流即可,不用改代码、不用重新打包本地安卓包。

# ========== 6) 已知差异(iOS)==========
#  - 没有音效(均衡器):那是安卓系统能力,iOS 下面板会显示「当前设备不支持」
#  - 后台播放/锁屏控制:已加 UIBackgroundModes=audio,正常
#  - 明文 http 接口:已加 ATS 例外;走 devtunnel 的 https 本来就没问题
